### Description of the exercise
You will work with Tropy to create a project. 
The research object is: the graphic production of the 2012 student movement Printemps érable (Montréal, Canada). 

### 1 Before starting: situate the dataset
Dataset: posters of the 2012 student protests in Montréal, Canada. [URL](https://zenodo.org/records/13936156) 

* Browse the website Printemps érable archives https://www.printempserable.net/ to see the collection of posters in context
* Consult the About page of the website to learn more about the event that triggered the initiative of creating the archive: https://www.printempserable.net/a-propos-about-us/ and the section explaining what is the Ecole de la montagne rouge https://www.printempserable.net/portfolio-item/edlmr/
* Consult the Wikipedia article if you need to learn more on the 2012 student protests in Montréal known as Printemps érable: https://en.wikipedia.org/wiki/2012_Quebec_student_protests  et

[Tropy tutorial](https://libguides.rice.edu/tropy/new-project)

Create a project. Get help from the tutorial if necessary. 

Import the image files of the dataset provided (posters of Printemps érable)

Explore the interface of Tropy

### 3 Start working with your sources
Describe your sources (create metadata!)

Once you imported your dataset, click on one image to have access to the form that you can use to enter metadata. 

* Explore the form: what does it consist of? Hos do you understand the difference between the item section and the photo section? 
* Explore from the menu of the item form types of forms that are available to you. Which one do you select to describe the data you work with? Why?
	* Are the available fields sufficient for describing your source? 
	* Are there fields you do not need? 
* Try to fill the form for at least two or three posters and a minima for the following fields: title, creator, date, archive, identifier, rights of use.
    * Discuss any issues that arise while doing this work
	* Is there information that you must repeat in exactly the same way for more than one sources?

### 4 Organising your sources 

* Browse your dataset and think if you can create chronological or thematic categories. Then try to create lists based on these categories and with help from the tutorial or the Tropy documentation. 
* Browse your dataset and the descriptions for each item. Think if there are keywords that would complete the description of each source and would help you find affinities between them.
